# 🌸 شهرِ بازی یاس و رنگ (نسخه اندروید کامل)

مجموعه کامل و ارتقاءیافته‌ی گرافیکی ۵ بازی دخترانه و خانوادگی با ته‌مایه‌ی سبک زندگی فاطمی، آماده ساخت خودکار فایل **APK اندروید** در GitHub Actions!

## 🚀 راهنمای ساخت فایل APK در گیت‌هاب (در ۳ دقیقه)

1. در سایت **GitHub** یک مخزن (Repository) جدید بسازید (مثلاً `shahr-bazi-yas`).
2. تمام فایل‌ها و پوشه‌های داخل این بسته را (به‌ویژه پوشه مخفی `.github` و پوشه `app`) داخل مخزن آپلود/Push کنید.
3. وارد تب **Actions** در بالای مخزن شوید؛ می‌بینید که گردش‌کار **Build ShahrBaziYas Android APK** به‌طور خودکار شروع به ساخت می‌کند (یا روی **Run workflow** کلیک کنید).
4. پس از حدود ۲ دقیقه تیک سبز می‌خورد. روی همان اجرا کلیک کنید و از بخش **Artifacts** فایل **`ShahrBaziYas-Android-APK`** را دانلود کرده، از حالت زیپ خارج کنید و فایل `ShahrBaziYas-Android-v1.0.apk` را روی گوشی یا تبلت اندروید نصب نمایید!

## ✨ امکانات نسخه اندروید
- کاملاً آفلاین و بدون تبلیغات
- ذخیره مستقیم عکس‌های یادگاری در گالری گوشی (`Pictures/ShahrBaziYas`)
- لرزش لطیف لمسی (Haptics) و موتور صوتی هارمونیک
- پشتیبانی هوشمند از دکمه بازگشت (Back) گوشی
- آیکون اختصاصی گل یاس و صفحه خوشامدگویی (Splash Screen)
